# YouTube Viral Trends Dashboard

An interactive, multi-page intelligence platform built with **Streamlit** and **Plotly** to decode the patterns behind viral content. This project processes metadata from thousands of trending videos to analyze engagement, sentiment, and category performance.

---

## Features
* **Emoji & Sentiment Intelligence:** Advanced extraction of viewer sentiment and emoji usage patterns from 100k+ comments.
* **Interactive Category Benchmarking:** Cross-comparison of Views, Likes, and Comment Rates across all major YouTube categories.
* **Engagement Correlation:** Statistical analysis of how Views, Likes, and Dislikes interact.
* **Metadata Analysis:** Exploring the relationship between video titles (punctuation/length) and viewer click-through rates.

## Tech Stack
* **Python** (Pandas, NLTK, Emoji)
* **Visualization:** Plotly Express, WordCloud
* **Architecture:** Streamlit Multi-Page API

## 🔧 Setup
1. Clone the repository.
2. Run `pip install -r requirements.txt`.
3. Launch via `streamlit run Home.py`.
